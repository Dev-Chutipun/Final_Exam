# รูปของร้านตัวอย่าง (ใช้กับ `go run ./cmd/seed`)

แต่ละร้านมี 2 โฟลเดอร์ ระบบรับรูปได้สูงสุด 3 รูปต่อร้าน:

- `cover/` เป็นรูปหน้าปกร้าน ใช้ 1 รูป แสดงในหน้ารายการร้านและเป็นรูปแรกในหน้าร้าน
- `menu/` เป็นรูปเมนูอาหาร ใช้ 2 รูป (เมนูที่ 1 และ 2 ในตารางด้านล่าง)

กติกา (เหมือนการอัปโหลดผ่านหน้าเว็บ):

- รับไฟล์ JPEG, PNG และ WebP ขนาดไม่เกิน 2 MB ต่อรูป ระบบตรวจชนิดจากเนื้อไฟล์ ไม่ดูจากนามสกุล
- ถ้ามีหลายไฟล์ ระบบเรียงตามชื่อไฟล์แล้วใช้ไฟล์แรก ๆ เช่น ตั้งชื่อ `1.jpg`, `2.jpg`
- ไฟล์ที่ชื่อขึ้นต้นด้วยจุด (เช่น `.gitkeep`) ระบบจะข้ามไป
- ช่องที่ไม่มีรูป seed จะใช้ภาพไล่สีพาสเทลแทน จึงรันได้แม้ยังไม่ใส่รูปเลย
- ถ้าไฟล์ไหนไม่ผ่านกติกา seed จะหยุดและบอกชื่อไฟล์นั้น
- ใช้รูปที่มีสิทธิ์ใช้ เช่น ถ่ายเอง หรือรูปจากเว็บที่อนุญาตให้ใช้ฟรี

ใส่รูปแล้วรันใหม่ด้วย `go run ./cmd/seed -reset` ในโฟลเดอร์ `backend/` (คำสั่งนี้ล้างข้อมูลทั้งหมด) ค่าเริ่มต้นของ `-images` คือ `../seed-images`
